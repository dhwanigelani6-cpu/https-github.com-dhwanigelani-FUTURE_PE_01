## Project Overview

Sarthana Cafe Copy Studio is a web-based project designed to help local businesses create clear, attractive and website-ready marketing content.

The project focuses on cafes and restaurants around Sarthana Jakatnaka, Surat, Gujarat.

It demonstrates how structured prompts can be used to prepare homepage copy, service descriptions, calls to action and SEO content.

## Objectives

- Understand local business requirements.
- Identify target audiences and business benefits.
- Generate homepage and service page content.
- Create persuasive calls to action.
- Adapt content to different brand tones.
- Document prompts, logic and generated outputs.

## Tools Used

- ChatGPT for prompt design and content generation
- Lovable for website development
- GitHub for project documentation
- Markdown for documenting prompts and outputs
